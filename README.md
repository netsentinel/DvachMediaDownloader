# DvachMediaDownloader

## ru

Позволяет скачивать медиа файлы из тредов двача и архивача. Поддерживает продолжение загрузки с того же места: перед скачиванием каждого файла проверяет, не был ли он загружен ранее.

## en

Allows you to download media files from 2ch and arhivach threads. Supports resuming downloads from the same place: before downloading each file, it checks whether it has been downloaded before.
